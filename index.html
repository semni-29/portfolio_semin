    About

    대중적이지 않은 여러 도메인을 모델링 연구와 부트캠프로 경험했습니다.

    컴퓨터공학 학사·석사 과정 동안 국가 R&D 과제 3건과 산학 기술애로 해결과제에 참여하며 의료 데이터를 다뤘습니다. 뇌질환 예측·예방(IITP ITRC), 메디컬 트윈 기반 시술 합병증 예측(KHIDI), 비대면 문진 시스템 개발 과제에서 논문 5편을 썼고, 그중 2편은 제1저자입니다.

    다른 도메인도 경험하기 위해 디지털하나로 2기, 경기도 빅데이터 전문가 과정을 수료하며 카드·통신·렌탈·리테일·플랫폼 분야의 실제 데이터를 다뤘습니다. 하나카드 결제 데이터 30만 건으로 타깃 마케팅 모델을 만들었고, 통신사 고객 이탈 예측과 리테일 RFM 세그멘테이션도 진행했습니다.

    모델 성능이 높게 나와도 그 지표가 해당 도메인에서 의미 있는 기준인지 먼저 따져보고, 고른 지표와 결과를 데이터를 잘 모르는 사람도 이해할 수 있게 설명하는 일을 좋아합니다.

    17프로젝트
    5논문 (제1저자 2)
    5국가 R&D · 산학 과제

    일하는 방식

    1

    지표 최고값이 아닌 일반화 성능으로 모델 선정

    • 통신사 이탈 예측 F1 최고 XGBoost(0.90)의 학습·검증 격차로 과적합 판정, AdaBoost(0.87) 채택
    • 카드 여행 예측 Recall 1위 Logistic Regression(0.88)이 Accuracy 0.57로 실무 최소선 미달, GBM 채택
    • TAVR 성능은 올랐지만 임상 검증이 불가능한 CTGAN 증강 데이터 제외
    2

    데이터 제약이 있으면 합성 데이터를 설계해 검증

    • 성범죄자 관리 구역 신상정보의 법적 활용 불가 확인 후 비식별 합성 데이터 직접 설계
    • 합성 원칙 공개 항목 형식만 모사, 실데이터 간 연결 차단, 인원수는 실제 통계 반영
    • 센서 오픈데이터 학습 → 실측 데이터 최종 검증의 2단계 구성
    3

    분석 결과를 서비스 화면까지 구현

    • TAVR 전역 설명과 환자별 설명을 나눈 Web Navigator
    • 에너지 Web·카카오톡 정보 구조 차등 설계로 3턴 이내 핵심 정보 도달
    • GIS · 실종아동 인터랙티브 지도, React·Node.js 웹 서비스

    핵심 역량

    데이터 제약 환경에서의 모델링불균형(80명 중 양성 5명)·소량·법적 활용 제한 데이터에서 검증 설계 선행
    근거 기반 모델 선정실무 최소 기준 충족 후 목적 지표로 선정, 학습·검증 격차 기반 과적합 판별
    설명가능 AI(XAI)변수중요도·SHAP·LIME 비교, 전역 설명과 환자별 설명을 분리한 대시보드
    이종 데이터 통합주기·잡음이 다른 센서 스트림 정합, 카드·크롤링·공공 API 데이터 결합
    CRM · 마케팅 분석RFM, K-means 군집화, LTV 재산정, 이탈·구매 예정 예측, 연관분석
    인프라 · 서비스 구현Kubernetes 모델 서빙(HPA·GPU·CI/CD·모니터링), Web·챗봇·GIS·대시보드
